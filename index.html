Step 1: Building Your First Web Page Locally

The very first step is to understand how a website works. For this reason, I want you to download this same folder and work from your computers. To make your first website you only need a single folder on your computer, two files, and a browser. That is all a web page really is. Download this, save it in your Desktop or another location that you will easily find it.

What is this folder?

Think of your project folder as a small library that lives on your desk. Right now, only you can open it. Your browser is the reader — when you open an index.html file, the browser reads it and displays it as a page, exactly like opening a book. No internet needed. No server in the cloud. Just your computer talking to itself.

📁 my-first-website/
    ├── index.html  ← the structure and content
    └── style.css   ← the colors and fonts (optional for now)

How does CSS connect to HTML?

Look at the <head> section at the top of this file. You will find a <style> block — that is where the CSS lives inside the HTML itself. The browser reads the <head> first, learns the visual rules, and then applies them as it renders the <body>.

For example, the CSS rule h1 { color: #bd5734; } tells the browser: "every time you see an <h1> tag, make the text that warm reddish-brown." The rule body { background-color: #e6e2d3; } sets the sandy background you are reading on right now.

💡 Try it: Open this file in a text editor, change #bd5734 to blue inside the h1 rule, save, and refresh your browser. You just edited a live design.

Why does this matter before GitHub?

Everything you see here — this layout, these colors, this text — is just two things: a file your browser can read, and CSS rules telling it how to look. In the next steps, we will take this exact folder and put it on GitHub, so that anyone in the world can open it in their browser, not just you.

The page does not change. The folder does not change. We are simply moving the library from your desk to a public shelf.
